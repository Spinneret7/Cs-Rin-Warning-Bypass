# Cs-Rin-Warning-Bypass
An user script I made on my free time that Auto-reveals unsafe links on cs.rin.ru forum, removes warnings except the banned websites ones as they are banned on the servers and database itself so it's impossible to bypass those ones! As it is annoying to get pampered abt bad hosts and good hosts lol.
## Installation
Just download the js file and load it into your User script engine such as Violent Monkey.
or just Click this link to [Install Script](https://github.com/Spinneret7/Cs-Rin-Warning-Bypass/raw/refs/heads/main/rin-links.js) and paste it on your user script engine!
